# GitHub-export

Detta paket är den kod- och dokumentcentrerade delen av Momentum-exporten.
Läs `docs/niva3_status_handoff.md` och `docs/HOLDOUT_STATUS.md` först.

Stora binära reproduktionsartefakter ligger i det separata forensiska paketet.
Lägg inte in API-nycklar eller lokala `.env`-filer före publicering. Paketet är
avsett att kunna initieras som ett nytt Git-repo eller kopieras till en särskild
granskad exportbranch.
